# 2D Platformer Template

Sistema reutilizável de movimentação para jogos de plataforma 2D desenvolvido em **Unity** e **C#**.

O objetivo deste projeto é reunir diferentes mecânicas de movimentação em uma estrutura modular que possa ser reutilizada e adaptada em diferentes projetos de jogos 2D.

## 🎮 Mecânicas

O sistema atualmente conta com:

- **Walk** - movimentação horizontal do personagem
- **Jump** - salto tradicional
- **Coyote Time** - permite realizar o salto por alguns instantes após deixar a plataforma
- **Dash** - movimento rápido em uma direção
- **Wall Jump** - salto utilizando paredes
- **Slide** - deslize pela parede
- **Grab** - agarrar-se às paredes
- **Extra Jump** - salto adicional no ar

## 🛠️ Tecnologias

- **Unity**
- **C#**
- **Unity Input System**

## 📚 Objetivo do projeto

Este projeto foi desenvolvido como parte do meu processo de estudo e aprimoramento em **programação de jogos**, com foco em sistemas de movimentação para jogos 2D.

A implementação inicial foi baseada em um tutorial disponível no YouTube. Durante o desenvolvimento, o código foi utilizado como ferramenta de estudo para compreender o funcionamento das diferentes mecânicas, adaptar a implementação e consolidar conhecimentos de programação em Unity e C#.

Mais do que simplesmente reproduzir o código, o objetivo foi entender **como e por que cada sistema funciona**, além de criar uma base que possa ser reutilizada em futuros projetos.

## 🧠 Principais conceitos estudados

Durante o desenvolvimento foram trabalhados conceitos como:

- Detecção de chão e paredes
- Física e movimentação através do `Rigidbody2D`
- Controle de velocidade
- Detecção de colisões
- Gerenciamento de estados de movimento
- Input System
- Coroutines e temporização
- Coyote Time
- Wall Jump
- Dash
- Controle de gravidade
- Organização e reutilização de código

## 🚀 Possíveis aplicações

A estrutura pode servir como base para diferentes tipos de jogos 2D, como:

- Platformers
- Precision Platformers
- Metroidvanias
- Action Platformers
- Jogos com foco em exploração e movimentação
